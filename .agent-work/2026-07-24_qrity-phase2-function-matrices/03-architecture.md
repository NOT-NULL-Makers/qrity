# 03 — Architecture

- Extend `qrity.matrix/function-matrix` with a version arity; retain zero-arity V1.
- Reuse the existing vector-of-vectors and construction cells.
- Depend on canonical version facts from `qrity.parameters`.
- Draw finder/separators, timing, alignments, metadata reservations, then fixed dark.
- Permit timing/alignment overlap only when polarity agrees; fail every other
  construction collision explicitly.
- Keep generalized specs local to `qrity.matrix`; do not weaken fixed `qrity.spec`.
- Leave `data-coordinates` and `place-data` fixed to Version 1 for the next commit.
